화면허용 개수초과 시 동작
문의 답변 이미지 첨부 (admin)최대 5장알럿 안내 후 초과분 제외
새 문의 접수 첨부파일 (cs)최대 5개알럿 안내 후 초과분 제외

다중 파일 선택형(첨부 버튼으로 여러 파일을 한 번에 선택)은 알럿(alert)으로 안내. 블록 추가형(콘텐츠 에디터에서 버튼 클릭으로 하나씩 추가)은 토스트(toast)로 안내하며, 한도 도달 시 블록 추가 버튼 자체가 더 이상 동작하지 않음.

시간대(타임존) 정책 신규

구분기준
저장KST 기준으로 저장(2026-08-19 정정 — 기존 "UTC로 통일 저장" 폐기)
admin 노출KST(한국 표준시) 고정 — 1차 admin 목표가 국내 운영팀 중심이므로
cs.html(고객) 노출 — 공지·업데이트 게시 일시 (목표, ⚠️ 구현 보류)골프장 소속 국가의 로컬 타임존으로 변환하여 표시 → 한국을 제외한 국가는 KST를 현지시간으로 환산해서 표시하되, KST 기준으로 계산된 값임을 함께 안내(2026-08-19 확정, ISSUE-079). 예: 2025.06.15 07:30 + (KST 09:30 기준 환산). 한국(ko) 조회 시엔 날짜만 표시
cs.html 표시 세부 (⚠️ 현재 임시 상태)위 목표를 구현하려면 국가별 UTC 오프셋이 필요한데, cs.html의 국가 전환 스위치가 현재 언어 선택기(8개 언어)라 국가와 1:1 매핑이 안 됨(English가 필리핀·말레이시아·싱가포르·미국·유럽·호주 6개국 공유 등) — 매핑 방식 확정 전까지 환산 기능 구현 보류. 잠정 조치로 한국 제외 국가에는 KST 원본 시각 + "KST" 라벨만 표시 중(예: 2025.06.15 09:30 KST)

해외 담당자의 admin 접근 관련 시간대 처리는 1차 범위 밖(1차엔 해외 담당자 admin 접근 자체가 없음). 날짜 단위 표시뿐 아니라 시각까지 필요한 문의 스레드 등에도 동일 기준 적용. 향후 클럽 위치 기반 로컬 타임존 제공으로 전환될 수 있음(2팀 인프라 검토 중) — 확정되면 재갱신 필요. 미결 사항: cs.html 국가·언어 선택기를 13개국 국가 선택기로 교체할지, 언어별 대표 국가 1곳으로 근사할지 결정 필요(ISSUE-079)

알림함·대시보드가 서로 다른 시점의 데이터를 보여주면 혼란을 겪으므로, 알림함과 대시보드는 동일한 실시간 데이터로 갱신된다. 내부 admin 사용자 수가 적어(1차는 국내 담당자만) 실시간 갱신 부하는 크지 않다고 판단.

구분갱신 방식
문의 목록이 바뀌는 이벤트(신규 접수, 답변 완료 처리 등)서버가 실시간으로 갱신 데이터를 전달(구체 기술은 개발 착수 시점에 결정)
"30분 이상 대기" 같은 시간 경과 계산클라이언트 로컬 타이머로 계산 — 서버 왕복 불필요
대시보드 지표 카드알림함과 동일한 실시간 데이터로 갱신

문의 상세 뒤로가기 방식 신규

페이지 단위로 확정(Q43, 2026-08-19) — 여러 문의를 옮겨 다니며 열어봤더라도, 뒤로가기는 항상 목록으로 한 번에 복귀한다. 문의 처리는 "목록 → 상세 확인/답변 → 목록 복귀" 흐름의 업무 화면이라, 열어본 개수만큼 뒤로가기를 눌러야 하는 "문의 단위" 방식(개발 선조치분)은 불필요한 클릭만 늘어난다고 판단해 폐기. 적용 범위는 cs.html(내 문의/골프장 문의) — admin 문의 관리는 목록·상세가 상시 분할 화면(split-pane)이라 "목록↔상세 페이지 전환" 자체가 없어 이 정책이 구조적으로 적용되지 않음.

알림·관련 문의로 특정 문의 진입 시 필터 초기화 신규

알림함 클릭이나 "관련 문의" 배너 클릭처럼 목록을 거치지 않고 특정 문의 1건으로 바로 진입하는 경우, 진입 전 걸려있던 국가/골프장/상태/정렬 필터를 전체 기본값으로 초기화한다(Q42, 2026-08-19). 필터를 유지하면 진입 대상이 그 필터 조건에 안 맞을 수 있어(예: "완료"로 필터링해둔 상태에서 "대기" 문의 알림 클릭) 목록에서 대상이 아예 사라져 보이는 문제가 있었음. "답변 대기 누적" 알림처럼 특정 카테고리 전체를 보여주는 목적의 진입은 예외 — 그 경우는 의도적으로 해당 필터를 적용한 채로 진입.
