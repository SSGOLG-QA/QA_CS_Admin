## 2. notice — 공지사항 관리

**화면 타이틀**: 공지사항 관리
**Primary 액션**: `새 공지 등록` → `openNoticeRegister()` → modal-notice

### 필터/검색 (`.filter-bar`)
- 전체 국가 (셀렉트, 국가 12종)
- 전체 솔루션 (셀렉트)
- 전체 상태 (셀렉트: 노출 / 미노출)
- 제목 검색... (텍스트 input, Enter)
- `검색` 버튼

### 테이블 컬럼 (`#notice-tbl` th 순서)
`제목` · `솔루션` · `적용 국가` · `노출여부` · `등록일` · `종료일`
- 행 클릭 → `openNoticeDetail(...)` (행 액션 버튼 없음, row-link)

### 여는 모달
- **modal-notice (공지사항 등록)** — 아래 전체 폼 필드
- modal-notice-detail (상세): 메타(솔루션·적용 국가·상태·게시 기간) + 번역 탭(원문 KO/EN/JA/TH/VI) + 푸터 `삭제`(btn-danger)·`닫기`·`번역 수정`·`수정`
- modal-register-confirm / modal-delete-confirm

#### [modal-notice] 공지사항 등록 — 폼 필드 (순서)
1. **제목** `*` — text input, maxlength 50, char-counter. hint: "적용 국가의 언어로 각각 번역되어 노출됩니다."
2. **솔루션** — select (전체 + 솔루션 11종)
3. **노출 여부** — toggle (checkbox, 기본 ON)
4. **게시 시작일** — date
5. **게시 만료일** — date (미입력 시 무기한 노출)
6. **적용 국가** — country-chip 그리드 (전체 기본 on)
7. **내용** — block-editor (text 블록 기본 + heading/text/image/video 추가)

푸터: `취소` / `임시저장`(+임시저장 내역 카운트 버튼) / `등록`(→register-confirm)

## 3. update — 업데이트 관리

**화면 타이틀**: 업데이트 관리
**Primary 액션**: `업데이트 등록` → `openUpdateRegister()` → modal-update

### 필터/검색
- 전체 국가 / 전체 솔루션 / 전체 상태(반영대기 / 반영완료) / `버전 또는 제목 검색...` input / `검색` 버튼

### 테이블 컬럼 (`#update-tbl` th 순서)
`버전` · `제목` · `솔루션` · `적용 국가` · `배포일시` · `상태`
- 행 클릭 → `openUpdateDetail(...)` (row-link)

### 여는 모달
- **modal-update (업데이트 등록)**
- modal-update-detail: 메타(버전·솔루션·적용 국가·배포일시·상태) + 번역 탭 + 푸터 `삭제`·`닫기`·`번역 수정`·`수정`
- modal-register-confirm / modal-delete-confirm

#### [modal-update] 업데이트 등록 — 폼 필드 (순서)
1. **버전** `*` — text (예: v4.2.1)
2. **업데이트 제목** `*` — text, maxlength 50, char-counter
3. **배포일시** — date + time (2개 input 한 행)
4. **상태** — select (반영대기 / 반영완료)
5. **적용 국가** — country-chip 그리드
6. **솔루션별 업데이트 내용** `*` — `솔루션 추가` 버튼으로 블록 동적 추가. 각 블록 = 솔루션 select(11종, 중복 방지) + block-editor(heading/text/image/video). ✕로 블록 삭제.

푸터: `취소` / `임시저장`(+카운트) / `등록`

## 4. guide — 솔루션 가이드 관리

**화면 타이틀**: 솔루션 가이드 관리
**Primary 액션**: `가이드 등록` → `openGuideRegister()` → modal-guide

### 필터/검색 (6개 컨트롤 — 모두 onchange 자동 필터)
- 전체 국가 (12종)
- 전체 솔루션 (11종)
- 전체 유형: 문제해결 / 업무 가이드 / 관리자 가이드
- 전체 분류: 초기 설정 / 설치·연결 / 기능 사용 / 기기 관리 / 계정·권한 / 데이터·연동
- 전체 상태: 노출 / 미노출
- `제목 검색...` input + `검색` 버튼

### 테이블 컬럼 (`#guide-tbl` th 순서)
`솔루션` · `제목` · `유형` · `분류` · `FAQ` · `적용 국가` · `상태` · `최종 수정`
- 행 클릭 → `openGuideDetail(...)` (row-link). 상태 셀에 `.guide-toggle` 뱃지(노출/미노출). 페이지당 기본 30개.

### 여는 모달
- **modal-guide (솔루션 가이드 등록, width 700)**
- modal-guide-detail: 메타(솔루션·유형·분류·적용 국가·최종 수정) + 번역 탭(KO/EN/JA/TH/VI) + 태그 + 관련 가이드 + 푸터 `삭제`·`닫기`·`번역 수정`·`수정`
- modal-category-edit (분류 관리): 분류 리스트 + `새 분류 이름 입력...` + `추가`
- modal-register-confirm / modal-delete-confirm

#### [modal-guide] 솔루션 가이드 등록 — 폼 필드 (순서)
1. **솔루션** `*` — select (11종)
2. **유형** `*` — select: 문제해결 가이드 / 업무 가이드 / 관리자 가이드
3. **분류** `*` — select: 초기 설정 / 설치·연결 / 기능 사용 / 기기 관리 / 계정·권한 / 데이터·연동
4. **노출 여부** — toggle (checkbox, 기본 ON)
5. **FAQ 지정** — checkbox "FAQ로 등록 (자주묻는질문에 노출)"
6. **제목** `*` — text, maxlength 50, char-counter. 제목 작성 헬퍼(주제 키워드 chips / 액션 chips / 문제·질문 유형 chips) 동적 노출.
7. **적용 국가** — country-chip 그리드
8. **가이드 내용** — block-editor (heading/text/image/video)
9. **관련 가이드 연결** — text 검색 콤보박스(최대 5개 다중 선택)
10. **태그** `*` — 태그 선택 영역 + 추천 태그(`guide-tag-suggestions`)

푸터: `취소` / `임시저장`(+카운트) / `등록`

## 6. quicktags — 빠른 검색 태그 관리

**화면 타이틀**: 빠른 검색 태그 관리
안내: "고객센터 검색창 아래 표시되는 태그입니다. 태그 클릭 시 연결된 가이드로 이동합니다. 최대 10개."

### 등록 태그 영역 (`#tag-list`)
- 태그 chip 10종 (태블릿 설치 / 사용자 등록 / 솔루션 도입 문의(미연결) / 경기관제 오류 / 카트 결제 안됨 / ERP 로그인 문제 / 셀프체크 화면 멈춤 / 업데이트 방법(미연결) / 무전 연결 오류 / 초기 설치 가이드). 각 chip에 `가이드 연결됨`/`미연결` 라벨 + `×` 삭제.
- 추가 행: `새 태그 입력` text + `연결할 가이드 선택` select + `추가` 버튼

### 태그 풀 (`.card` "태그 풀")
"가이드 등록에 사용되는 전체 태그 목록". 솔루션별 섹션(🌍 공통 / 경기관제 / ERP / 테이블오더 / 카트내결제 / 무전 / 셀프체크 / 블랙박스 / 대기호출 / 데이터마케팅 / 코스관리), 각 섹션 하위 분류 라벨(오류 유형·기능·기기·설정 등)에 `.tag-suggestion-chip` 다수.

**테이블/필터 없음.**

## 7. inquiry — 문의 (목록 + 상세 2단 레이아웃)

**화면 타이틀**: 좌 `문의 목록` / 우 `문의 상세`
좌측 목록 헤더에 `N 대기` 뱃지.

### 좌측 필터 (목록)
- 전체 국가 (12종, onchange 골프장 필터 갱신)
- 전체 골프장 (Seoul GC / Pine Valley GC / Bangkok Royal GC / Osaka GC / Sydney GC)
- 정렬: 최신순 / 오래된순
- 상태: 전체 / 답변 대기 / 진행중 / 답변 완료
- 목록 항목: 제목 + 메타(국가·골프장·솔루션·시각) + 상태 뱃지. 클릭 → `openInquiryDetail(idx)`. 빈 상태: "검색 결과가 없습니다."

### 우측 상세
- 헤더: 솔루션 뱃지 + 상태 뱃지 + `완료 처리` 버튼(`toggleInquiryStatus`)
- 번역 바: "원문: English → 관리자 표시: 한국어", "자동 번역 활성"
- 관련 문의 배너(조건부)
- 스레드(`.inq-thread`): 고객/관리자 말풍선, 첨부 이미지(라이트박스), 번역 보기 토글
- **답변 작성(`.reply-box`)**:
  - 툴바: "한국어로 작성 중" / "영어로 자동 번역 후 고객에게 발송"
  - textarea (placeholder: "답변을 한국어로 작성하세요. 자동으로 영어로 번역되어 발송됩니다.")
  - 이미지 첨부(`이미지` 버튼, file input, 최대 5장)
  - `답변 발송` 버튼 (`sendReply`)

**테이블 없음** (리스트/스레드 구조). 등록 모달 없음.
