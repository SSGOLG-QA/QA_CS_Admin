## 5. 누락되기 쉬운 테스트 포인트

### 5-1. 경계값 (임계값 하한-1 / 하한 / 하한+1 형태 3종 세트)
- 새 문의 **제목 50자**: 49자 / 50자 / 51자(초과 입력 차단·카운터 0/50) — R6
- 첨부 **개수 5개**: 4개 / 5개 / 6개(6번째 알럿 후 제외) — R5·R6
- 이미지 **10MB**: 10MB 이하 / 정확히 10MB / 10MB 초과(알럿 후 초기화) — R6
- 영상 **50MB**: 50MB 이하 / 50MB / 50MB 초과 — R6
- 공지/가이드 **페이지네이션 30**: 30건(1페이지) / 31건(2페이지 생성) / 60건 경계 — R1·R3
- 업데이트 **더보기 10**: 10건(더보기 숨김) / 11건(더보기 1회) / 21건(2회) — R2
- 홈 노출 개수: 공지 3/4/5건일 때 정확히 4개까지만 — R7
- 관련 가이드 **5개**: 4개 / 5개(만석·추가 차단) / 6개 시도 — R3

### 5-2. 권한 (역할별 접근)
- 클라우드 로그인만으로 전원 접근 가능 확인(별도 서비스 권한 불요) — R8
- 골프장 문의: 타 골프장 문의 열람 범위·본인 골프장 한정 여부 — R5
- 문의자 표기: 클라우드 설정 이름 노출("접수자" 아닌 "문의자") — R5
- 서버측 권한 재검증(ISSUE-069) — 클라이언트 우회 접근 차단 — R8

### 5-3. 예외·엣지 케이스 (비정상 플로우·상태 전이·동시성)
- 답변 완료 문의 스레드 잠금 → 재질문 불가 → "새 문의 접수" 분기(관련 문의 칩) — R5
- 실시간 10초 폴링: 상세 열어둔 채 상대 메시지 수신 시 반영 / 폴링 중 완료→재오픈 전이 — R5
- 번역 3상태 전이: 번역중→완료 / 번역중→5회 실패→원문만 — R5·A5
- 만료일 도래 공지: 만료 시점 목록/상세 노출 종료 타이밍 — R1
- 빈 상태: 각 화면 0건 문구("등록된 공지사항이 없습니다." 등) — R1·R7
- 업데이트 반영대기 항목이 고객 화면에 새어 노출되지 않는지(C3) — R2

### 5-4. 데이터 정합성 (상태 전환 후 DB↔화면 불일치)
- 홈 문의 stat **전체 = 대기 + 진행중 + 완료** (실측 76=18+27+31 ✅ 회귀 감시) — R7
- 복수 솔루션 업데이트가 해당 솔루션 탭 **전부**에 동일하게 노출 — R2
- 원문 수정 시 전체 언어 재번역 후 화면 반영 일관성 — R5·R6
- 정렬(등록일 내림차순) 실데이터 일관성(ISSUE-063) — R1·R2

### 5-5. B2B 환경변수 (골프장별 옵션·역할)
- **옵션 미도입 골프장**: 특정 솔루션(예 코스관리) 미도입 골프장에서 해당 솔루션 탭/공지/가이드 노출 여부 — R1·R3
- 솔루션 필터 12탭이 골프장 도입 솔루션과 무관하게 항상 12개인지, 도입분만 노출인지(현 실구현=항상 12) — 확인 필요
- 역할별(경기팀/운영관리자/캐디/식음료팀) 고객 화면 차이 — 현 정책상 클라우드 로그인 전원 동일 접근인지 재확인 — R8
- 클럽 전환(여러 골프장 관리 계정) 시 문의/공지 컨텍스트 분리 — R5
