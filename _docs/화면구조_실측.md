## ✅ 정합 (정책 일치)
- 제목 50자(maxlength=50) · 상세 무제한 · 첨부 accept=JPG/PNG/MP4/MOV
- 가이드 유형 4·분류 6 · 문의 상태 3단계 · 공지 페이지네이션 · 업데이트 더보기
- 홈 문의 stat **계산 정합**: 전체 76 = 대기 18 + 진행중 27 + 완료 31 (불변식 성립)

## ≠ 기획-구현 차이(diff) 후보 — Phase 2에서 diff() 기록
1. **솔루션명**: 정책/tag_pool "무전" → 실구현 **"무전기"** (전 화면)
2. **문의 상태 라벨 불일치(화면 내)**: 홈 stat = "답변 대기/답변 완료"(풀) ↔ 목록 탭 = "대기/완료"(축약)
3. **새 문의 솔루션 SELECT에 "전체 솔루션" 포함(12opts)**: 접수 폼은 필수 단일 선택(11)이어야 하는데 "전체"가 옵션에 있음 — 검증 요(오선택 가드 여부)
