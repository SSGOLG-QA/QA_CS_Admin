# 공통 UI 규칙

---

## [삭제] 확인 팝업

삭제 버튼 클릭 시 공통으로 사용하는 확인 다이얼로그 규격.

### 워딩

| 요소 | 텍스트 |
|---|---|
| 제목 | 정말 삭제하시겠어요? |
| 본문 | 삭제된 내용은 복구할 수 없습니다. |
| 취소 버튼 | 취소 |
| 확인 버튼 | 삭제 |

### 버튼 스타일

| 버튼 | 클래스 | 위치 |
|---|---|---|
| 취소 | `btn btn-outline` | 좌측 |
| 삭제 | `btn btn-danger` | 우측 |

### 적용 대상

- 공지사항 상세 모달 → 삭제
- 업데이트 상세 모달 → 삭제
- 솔루션 가이드 상세 모달 → 삭제
- FAQ 상세 모달 → FAQ 해제
- (이후 추가되는 모든 삭제 액션)

> FAQ 해제는 "정말 삭제하시겠어요?" 대신 **"FAQ에서 해제하시겠어요?"** / "해제된 항목은 FAQ 목록에서 제거됩니다." 로 워딩 변경 적용

## [등록] 확인 팝업

등록 버튼 클릭 시 공통으로 사용하는 확인 다이얼로그 규격.

### 워딩

| 콘텐츠 유형 | 제목 | 본문 |
|---|---|---|
| 공지사항 | {유형}을 등록하시겠어요? | 등록 후 노출 여부 설정에 따라 즉시 반영됩니다. |
| 업데이트 | 업데이트를 등록하시겠어요? | 등록 후 즉시 업데이트 목록에 반영됩니다. |
| 솔루션 가이드 | 솔루션 가이드를 등록하시겠어요? | 등록 후 즉시 가이드 목록에 반영됩니다. |
| (신규 추가 시) | {콘텐츠명}을 등록하시겠어요? | 등록 후 즉시 {목록명}에 반영됩니다. |

### 버튼 스타일

| 버튼 | 클래스 | 위치 |
|---|---|---|
| 취소 | `btn btn-outline` | 좌측 |
| 등록 | `btn btn-primary` | 우측 |

### 적용 대상

- 공지사항 등록 모달 → 등록
- 업데이트 등록 모달 → 등록
- 솔루션 가이드 등록 모달 → 등록
- (이후 추가되는 모든 등록 액션)

> 삭제 확인 팝업과 동일한 모달 구조를 사용하되, 액션 버튼 스타일만 `btn-danger` → `btn-primary`로 변경

> **수정 모드**일 때는 제목을 **"저장하시겠어요?"** / 본문 "수정된 내용이 즉시 반영됩니다."로 변경 적용

## 토스트 팝업

확인 팝업에서 Y 버튼 클릭 후 공통으로 표시하는 완료 메시지 규격.

### 동작

- 화면 하단 중앙 고정 노출
- 2.4초 후 자동 소멸
- 애니메이션: 아래에서 위로 슬라이드 인/아웃

### 메시지 규칙

| 액션 | 토스트 메시지 |
|---|---|
| 등록 | {콘텐츠명}이 등록되었습니다. |
| 저장 (수정) | 저장되었습니다. |
| 삭제 | 삭제되었습니다. |
| FAQ 해제 | FAQ에서 해제되었습니다. |

### 스타일

- 배경: `#1c1e54` (brand-dark-900)
- 텍스트: 흰색, 13px
- 모양: 알약형 (border-radius: 9999px)
