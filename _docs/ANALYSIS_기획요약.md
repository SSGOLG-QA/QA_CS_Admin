## 2. IA 구조 (프로토타입 기준 — 실측 후 보정)
**운영자(admin)** 좌측 사이드바
- 대시보드
- 콘텐츠 관리: 공지사항 / 업데이트 / 솔루션 가이드 / 자주 묻는 질문(FAQ) / 빠른 검색 태그

**고객(cs)** 상단 GNB
- 홈 / 공지사항 / 업데이트 / 솔루션 가이드 / FAQ / 내 문의 / 골프장 문의 (+ 새 문의 접수)

## 4. admin ↔ cs 차등 노출 (최다 검증 포인트)
- 업데이트: **반영완료만** cs 노출, 상태 텍스트 자체는 숨김.
- 공지 날짜: cs는 라벨 없이 날짜만, "무기한" 텍스트 미표기(admin은 표기).
- 문의 건수: cs는 홈 stat에만, 목록엔 미표시.
- 이미지 라이트박스: 조회 시점만, admin은 사용자 발신 이미지만 확대.
